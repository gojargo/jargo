# Guides

Task-oriented pages for the subsystems around the core engine.

- **[Turn-taking](turn-taking.md)** — Silero VAD + Smart Turn v3: when the bot
  answers, and when the user can cut in. The setting that most decides whether a
  bot feels good.
- **[Services](services.md)** — swapping STT/LLM/TTS providers, tool calling, and
  speech-to-speech.
- **[Audio](audio.md)** — codecs, sample rates, noise reduction, background
  mixing, recording.
- **[Telephony](telephony.md)** — phone calls over Twilio, Telnyx, Plivo and
  Exotel, plus DTMF and the idle watchdog.
- **[RTVI](rtvi.md)** — the event protocol that gives a client live transcriptions
  and speaking state.
- **[Observability](observability.md)** — observers, metrics and tracing, and which
  numbers actually matter for a voice agent.
